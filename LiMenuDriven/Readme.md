# List Management System

## 📌 Project Overview

The List Management System is a menu-driven Python application that allows users to perform basic CRUD (Create, Read, Update, Delete) operations on a list. This project helps beginners understand list manipulation, loops, conditional statements, and menu-driven programming in Python.

---

## 🚀 Features

- Create a List
- Display (Read) List Elements
- Delete an Element Using Index
- Update an Element Using Index
- Exit the Program

---

## 🛠️ Technologies Used

- Python 3
- Lists
- Loops
- Conditional Statements
- Match-Case Statement

---


```bash
python ListMenuDriven.py
```
