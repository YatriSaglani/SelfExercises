# Array Operations Hub

## 📌 Project Overview
Array Operations Hub is a menu-driven Python program that allows users to create an array and perform various operations on it through an interactive menu. This project demonstrates the use of arrays (lists), loops, conditional statements, and Python's built-in functions.

## 🚀 Features

- Create an Array
- Find the Largest Element
- Find the Smallest Element
- Identify Odd and Even Elements
- Reverse the Array
- Search for an Element
- Count the Frequency of an Element
- Exit the Program

## 🛠️ Technologies Used

- Python 3
- Lists (Arrays)
- Loops
- Conditional Statements
- Match-Case



```bash
python ArrayMenuDriven.py
```
