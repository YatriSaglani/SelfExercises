# 🧮 Scientific Math Toolkit

## 📌 Overview

Scientific Math Toolkit is an interactive console-based Python application developed within a Jupyter Notebook. The program provides a comprehensive suite of mathematical, algebraic, exponential, logarithmic, and trigonometric utilities through a clean, menu-driven interface[cite: 1].

This project is designed to showcase concepts like:

* Interactive Menu Loops using `match-case` statements[cite: 1]
* Array Manipulation & State Management[cite: 1]
* Mathematical Built-in Functions & Standard Modules[cite: 1]
* Numerical Operations with NumPy
* Trigonometric & Scientific Calculations

---

## 🚀 Features

### 1️⃣ Enter Number / Array Input

* Accepts user input to update the active numerical array or dataset[cite: 1].

### 2️⃣ Square & Square Root Calculation

* Computes the square ($x^2$) and square root ($\sqrt{x}$) of the target number.

### 3️⃣ Power & Absolute Values

* Evaluates exponential powers ($x^y$) and absolute values ($\vert{}x\vert{}$).

### 4️⃣ Exponential & Logarithmic Functions

* Calculates natural exponential values ($e^x$) and logarithms ($\ln x$ / $\log x$)[cite: 1, 3].

### 5️⃣ Trigonometric Calculations

* Computes Sine ($\sin x$), Cosine ($\cos x$), and Tangent ($\tan x$) for standard or radial inputs[cite: 1, 3].

### 6️⃣ Rounding Functions (Ceil & Floor)

* Calculates the Ceiling ($\lceil x \rceil$) and Floor ($\lfloor x \rfloor$) bounds of numerical values[cite: 1, 3].

### 7️⃣ Display Current Array

* Displays the updated stored values currently held in memory[cite: 1].

### 8️⃣ Exit Program

* Safely exits the main application loop[cite: 1].
